About

Electronics Engineer building at the hardware-software boundary

I'm an Electronics Engineer based in Davao, Philippines, with hands-on experience in embedded systems, IoT hardware design, and firmware development. My background spans PCB design, BLE, LoRaWAN, and microcontroller programming — the kind of low-level work that most software engineers never touch.

I'm currently expanding into software automation, AI-powered workflows, and network security — building toward a fully remote role in systems engineering. I build things that cross the boundary between physical hardware and connected software: from sensor nodes in the field to cloud dashboards tracking them in real time.

Outside of engineering, I'm developing a smart hydroponics farm and a long-term farm-to-table café project — both powered by the same embedded + automation skills I use professionally.
